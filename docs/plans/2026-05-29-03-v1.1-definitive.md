## § 2 — Frugality Hierarchy

```
TIER 0 — In-context / no tool call
TIER 1 — Local OSS (Ollama, LM Studio Mac/Win)
TIER 2 — Local indexes (gbrain pgvector, CRG SQLite)
TIER 3 — Free remote OSS (HuggingFace Inference free)
TIER 4 — Free-tier proprietary (Gemini free, Brave)
TIER 5 — Paid  ← OpenRouter tiered pipeline lives here (P2)
TIER 6 — Last resort (Grok — explicit budget approval)
```

Stop at first eligible tier. `ORAMASYS_OFFLINE=1` rejects tier ≥ 3.

## § 10 — Architectural Decision Log

| Decision | Rationale |
|---|---|
| Rename before pipelines | Pipeline metadata would embed `UltraThink*` names → double churn |
| Frugality router before OpenRouter | OpenRouter must enter as governed Tier-5, not ungoverned parallel |
| OpenRouter as Tier-5 impl | Reconciles local-first hierarchy with cheap→strong optimization |
| PT owns OPENROUTER_API_KEY | orama is stateless; secrets authority is PT always |
| PIPELINE_TIERED_ENABLED=0 default | "5–10× savings" is hypothesis; measure before enabling |
| 3 always + 5 trigger sub-skills | AFRP/CIDF/gstack are session-core; others bloat every session |
