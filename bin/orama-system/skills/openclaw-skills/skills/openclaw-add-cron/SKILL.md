## Purpose
Create scheduled jobs in OpenClaw without breaking the symlinked cron state. This skill supports `cron`, `every`, and `at` schedule types with consistent job schema. It defaults to isolated execution to avoid context bleed and control cost.

## When to Use
- Scheduling recurring maintenance or memory jobs
- Adding one-shot delayed tasks
- Migrating ad hoc schedules into versioned config

## Inputs
- Required:
  - `job_id`
  - `agent_id`
  - `schedule_type` (`cron|every|at`)
  - `schedule_value` (expression, interval, or timestamp)
  - `prompt`
- Optional:
  - `isolated` (default `true`)
  - `enabled` (default `true`)

## Procedure
1. Validate schedule inputs.
```bash
set -euo pipefail
case "$schedule_type" in cron|every|at) ;; *) echo "invalid schedule_type" >&2; exit 1;; esac
[ -n "$job_id" ] && [ -n "$agent_id" ] && [ -n "$schedule_value" ] && [ -n "$prompt" ]
```
2. Append or update cron job in `openclaw.json`.
```bash
jq --arg id "$job_id" --arg aid "$agent_id" --arg t "$schedule_type" --arg v "$schedule_value" --arg p "$prompt" '
  (.cron.jobs //= []) |
  .cron.jobs |= map(select(.id != $id)) + [{
    id:$id,
    agentId:$aid,
    schedule:{type:$t,value:$v},
    prompt:$p,
    isolated:true,
    enabled:true
  }]
' openclaw.json > openclaw.json.tmp && mv openclaw.json.tmp openclaw.json
```
3. Remove transient `jobs.json` before deployment.
```bash
rm -f ~/.openclaw/cron/jobs.json
```
4. Deploy with stow.
```bash
stow --no-folding -t "$HOME" .
```
5. Restart gateway and wait.
```bash
launchctl kickstart -k "gui/$(id -u)/com.openclaw.gateway"
sleep 5
```
6. Verify job materialization.
```bash
jq '.cron.jobs[] | select(.id=="'"$job_id"'")' openclaw.json
```
7. Verify runtime logs for scheduler load.
```bash
log show --style syslog --last 5m --predicate 'eventMessage CONTAINS[c] "cron" OR eventMessage CONTAINS[c] "scheduler"' | tail -n 120
```

## Output Contract
```json
{
  "status": "ok|error",
  "files_modified": ["openclaw.json"],
  "follow_up_actions": ["openclaw-status", "observe-next-run"]
}
```

## Naming Enforcement
- `job_id` should be lowercase-hyphen format.
- `agent_id` must match an existing lowercase-hyphen agent ID.
- `schedule.type` must be exactly one of `cron`, `every`, `at`.

## Gotchas
- `~/.openclaw/cron/jobs.json` is regenerated by gateway and must be treated as transient.
- Forgetting `rm -f ~/.openclaw/cron/jobs.json` can break stow symlink behavior.
- Non-isolated cron sessions can inflate context cost and produce cross-task leakage.
